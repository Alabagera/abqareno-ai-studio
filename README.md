# Abqareno AI Studio

أريد إنشاء موقع شخصي باسم "عبقرينو  AI Studio". الموقع باللغة العربية ويدعم جميع الهواتف .

Alabagera Ai

أريد لوحة تحكم لإنشاء فيديوهات من صورتي وصوتي، مع رفع صورة، إدخال نص، تحويل النص   إلى صوت، ثم إنشاء فيديو Talking Avatar. أريد تصميمًا احترافيًا باللون الأزرق والذهبي، مع صفحة تسجيل دخول ولوحة تحكم وسجل للفيديوهات.

واريد لاحقا إضافة أدوات ونمادج ذكاء اصطناعي مختلفة من مصادر مفتوحة 

لذا اجعل الموقع يكون قايلا لذلك. 

واريده أن يتقبل رفع صور وفيديوهات وصوتيات ومستندات 

ثم تبدأ معي ميزة واحدة في كل مرة بدل أن اطلب منك المشروع كله مرة واحدة.

والميزة المهمة أن Lovable يدعم العمل مع GitHub، وبالتالي لا يكون الكود محبوسًا داخلك. حيث يمكنني إضافة الكود إلى حسابي في GitHub

أنا لا اريد أن تبدأ ببناء الذكاء الاصطناعي داخل الموقع أولًا.

اعمل مرحلتين:

المرحلة 1 موقعي + لوحة التحكم + رفع الصورة + إدخال النص + مكتبة الفيديوهات + التصميم.

مع إتاحة إمكانية إضافة باقي العناصر فيديو صوت مستند 

وإمكانية تحويل الصوتي التلقائي إلى نص في الفديوهات بألوان جملية وخطوط منسقة.. والترجمة أيضا. 

المرحلة 2 نربط الموقع بالنماذج المفتوحة التي نريدها :

كمثال اولي XTTS-v2 

صوتي → نموذج الصوت → صورتي → نموذج تحريك الوجه → FFmpeg → الفيديو النهائي

وبهذا لو أردت تغيير نموذج الذكاء الاصطناعي لاحقًا، لا تحتاج إعادة بناء الموقع.
